# Security and sample data

This repository is a curated portfolio source release. Do not commit credentials, local environment files, database files, uploaded documents, or real customer data. Use only synthetic records when demonstrating the application.

A source scan is not a certification of deployment security. Review authorization, privacy, retention, dependency advisories, and provider configuration before operating any fork with real users. Report a security concern privately through the maintainer's contact link on the README; do not place credentials or personal records in a public issue.
